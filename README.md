# أمير — مصمم جرافيك وهوية بصرية

موقع أعمال شخصي عربي باتجاه RTL، مبني بملف HTML واحد، مع تصميم متجاوب للهواتف والأجهزة اللوحية والشاشات الكبيرة.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو انشر المستودع باستخدام GitHub Pages.

## التخصيص

- عدّل الاسم ومعلومات التواصل في `index.html`.
- استبدل روابط الصور التجريبية بروابط صور أعمالك.
- عدّل روابط Instagram وBehance إلى حساباتك.
- الصور الحالية تجريبية ومستضافة على Unsplash، والخطوط تُحمّل من Google Fonts.
